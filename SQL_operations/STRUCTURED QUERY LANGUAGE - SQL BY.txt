SQL CURSOR
CURSOR -> CURSOR IS BLOCK OF MEMORY THAT HOLD QUERY DEFINITON IN HEADER AND ROWID THAT SATISFIED THE QUERY AS STORED 
IMPLICIT CURSOR -> CREATED BY SYSTEM, WHENEVER SELECT OR CRUD OPERATION ARE EXECUTED. BUT APPLICATION DOES NOT HAVE ANY KIND OF CONTROL ON CURSOR.
EXPLICIT CURSOR -> CREATED BY SQL DECLARED CURSOR NAME CURSOR, APPLICATION HAS CONTROL OVER CURSOR FOR FETCHING THE ROW.

HANDLING EXPLICIT CURSOR
DECLARE CURNAME                     CREATES EXPLICIT CURSOR.
OPEN CURNAME                        APPLICATION OBTAINS HANDLE(POINTER) TO THE CURSOR.
FETCH FROM CURNAME                  APPLICATION FETCHES ONE ROW FROM CURSOR.
CLOSE CURNAME                       DELETES THE CURSOR DEFINITION.
